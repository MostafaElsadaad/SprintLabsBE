# Manual collection
Seven starter requests; no automated runner or live verification claim. Set baseUrl and credentials privately in local Postman variables. Use platform admin accessToken for seed/preview/reset, then player accessToken for reads/claims. GameServerCredential is server-only. Set fresh stable eventId, numeric playerProfileId and occurredAtUtc with Z. Event request substitutes numeric ID into a JSON string; ASP.NET Core permits quoted numeric IDs. For batch/configuration examples see api.md. Do not export populated credentials. Seed requests persist test missions/rewards/items and are intended for a disposable or development database.
