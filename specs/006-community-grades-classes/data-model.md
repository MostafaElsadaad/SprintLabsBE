# Data Model: Community Grades and Classes

## Overview

This feature adds two community-owned entities:

- `Grade`
- `Class`

Both are scoped to a `Community`. Class records are soft deleted through `ClassStatus` rather than hard deletion.

## Grade

Represents a grade grouping within one community.

| Field | Type | Validation |
|---|---|---|
| Id | 64-bit identifier | Generated by storage |
| CommunityId | 64-bit identifier | Required; must reference existing Community |
| Name | String | Required, trimmed, max length planned as 120 |
| SortOrder | Integer | Required, non-negative |
| CreatedAt | Timestamp | Required, defaults to current UTC/database timestamp |

### Relationships

- Community 1 -> 0..* Grades
- Grade 1 -> 0..* Classes

### Grade Rules

- Grades are created only by Active Owners or Active Teachers.
- Grades are listed only by Active Owners or Active Teachers.
- Grade list returns class count per grade.
- Class count includes only Active classes.
- Grade update and delete are not in scope.

## Class

Represents a class under a grade within one community.

| Field | Type | Validation |
|---|---|---|
| Id | 64-bit identifier | Generated by storage |
| CommunityId | 64-bit identifier | Required; must reference existing Community |
| GradeId | 64-bit identifier | Required; must reference Grade in same Community |
| Name | String | Required, trimmed, max length planned as 120 |
| Status | ClassStatus | Required, defaults to Active |
| CreatedAt | Timestamp | Required, defaults to current UTC/database timestamp |
| UpdatedAt | Nullable timestamp | Set on update and soft delete |

### Relationships

- Community 1 -> 0..* Classes
- Grade 1 -> 0..* Classes
- Class 1 -> 1 Grade

### ClassStatus

| Value | Meaning |
|---|---|
| Active | Visible in class lists and counted in grade class counts |
| Deleted | Soft deleted; excluded from lists and counts |

### Class State Transitions

```text
Active
  -> update name/grade
Active

Active
  -> soft delete
Deleted

Deleted
  -> update rejected
Deleted

Deleted
  -> delete again is idempotent or no-op without hard delete
Deleted
```

## Community Membership

Authorization is based on existing community membership.

| Membership | Manage grades | Manage classes |
|---|---:|---:|
| Active Owner | Yes | Yes |
| Active Teacher | Yes | Yes |
| Active Student | No | No |
| Pending Owner/Teacher/Student | No | No |
| Removed Owner/Teacher/Student | No | No |
| No membership | No | No |
| Platform admin without Active Owner/Teacher membership | No | No |

## Ownership and Validation Rules

- Route `communityId` is the tenant boundary for every operation.
- Create class validates `gradeId` belongs to route `communityId`.
- List classes with `gradeId` validates the grade belongs to route `communityId`.
- Update class validates `classId` belongs to route `communityId`.
- Update class validates the target `gradeId` belongs to route `communityId`.
- Delete class validates `classId` belongs to route `communityId`.
- Deleted classes are excluded from:
  - GET classes
  - GET classes with grade filter
  - Grade list class counts

## Planned EF Configuration

- `Grade.Name`: required, max length 120.
- `Class.Name`: required, max length 120.
- `Grade.CreatedAt` and `Class.CreatedAt`: required default timestamp.
- `Class.Status`: required default `Active`.
- `Grade.CommunityId` FK to `Community`.
- `Class.CommunityId` FK to `Community`.
- `Class.GradeId` FK to `Grade`.
- Indexes:
  - `Grades.CommunityId`
  - `Grades.CommunityId, SortOrder`
  - `Classes.CommunityId`
  - `Classes.GradeId`
  - `Classes.CommunityId, Status`
